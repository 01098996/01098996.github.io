回答知识库里的概念/科普问题，同时直接从实时数据源拿价格、市值、资金费率（funding rate）、TVL（Total Value Locked，总锁仓量）和市场情绪。拿市场数据不需要任何 API key。

架构理念

crypto RAG 的核心原则就一条，市场数值绝不能塞进向量存储（vector store），一进去就过时。数值类数据（价格、资金费率、TVL）在查询时通过工具调用（tool-call）实时拉取，RAG 只管概念、描述和静态上下文。数值从来不经过大语言模型（LLM），所以价格幻觉（hallucination）这个问题根本不存在。

功能

实时市场数据（无需密钥）

- 现货价格来自 6 家交易所（Binance、OKX、Bybit、KuCoin、Kraken、Coinbase），可横向对比价差和套利机会
- 通过 Binance WebSocket 实现亚秒级价格流（--watch、--live）
- 历史价格走势来自 Binance OHLC K 线（Open-High-Low-Close，开高低收）。配合 SMA（Simple Moving Average，简单移动平均线）做方向分析
- 给定名义金额，估算订单簿深度（order book depth）与滑点（slippage）
- 资金费率与未平仓合约量（Binance Futures）
- 协议级与各链 TVL（DefiLlama）
- 恐惧贪婪指数（Fear & Greed Index，含趋势）
- 全球市场概览，包括总市值、BTC/ETH 占比，以及当日涨幅/跌幅榜
- 链上实时数据，包括 Bitcoin 手续费与内存池（Mempool.space）、BTC 网络算力与交易数、难度与减半倒计时、Ethereum Gas 费（EIP-1559）、稳定币供应量（DefiLlama）、24 小时 DEX 交易量、Solana 供应量/epoch/通胀率RAG

- 混合检索走 BM25（关键词）+ 稠密向量嵌入（FAISS），最后用 Reciprocal Rank Fusion（RRF，倒数排序融合）合并
- 可选 cross-encoder 重排序器（reranker，启用参数 --rerank）
- 知识库收录 146+ 印尼语主题，涵盖概念、技术、分类、交易、风险、协议、策略、历史、网络、安全、指标、生态、实践、高级协议、监管
- 币种分类过滤（DeFi、迷因币、AI、稳定币、Layer-1 等），共标记 615 个币种用户功能

- 带追问记忆的交互式聊天，无参数时默认启动
- 多币种监听模式，支持条件价格告警，比如 BTC>65000、ETH<1800
- 投资组合追踪器，可以添加持仓、实时计算价值、查看 P/L（盈亏）和资产配置
- LLM 输出按 token 流式呈现（--stream）
- 工具调用智能体（tool-calling agent），复杂或多步查询会自动路由给 LLM，由 LLM 自己选工具。比如「比较 BTC 和 ETH 的资金费率」、「哪个 DeFi 币的资金费率最高」

编辑导读

基于RAG架构的印尼语加密货币助手，覆盖267个知识主题，整合6家交易所的实时行情、WebSocket数据、衍生品、链上指标、DeFi信息，并附带工具调用智能体与LLM合成层。仓库获97星，为面向东南亚加密市场分析的多语言应用参考。
