bsab/france-mcp-servers

官方服务器（Official server）；其公开文档化的端点使用 Streamable HTTP，没有访问限制。不支持直接的 stdio 和 SSE。也提供了自托管（self-hosting）说明。

Légifrance MCP

社区版 Python 服务器，通过 Streamable HTTP 自托管。需要 PISTE Légifrance 订阅以及 LEGIFRANCE_CLIENT_ID/LEGIFRANCE_CLIENT_SECRET。未声明有公开托管。

Judilibre MCP

社区版 Python 服务器，通过 Streamable HTTP 自托管。需要 PISTE Judilibre 订阅以及 JUDILIBRE_CLIENT_ID/JUDILIBRE_CLIENT_SECRET。未声明有公开托管。

INSEE Entreprises MCP

源码安装（Source installation），需要 Python 3.12+ 和 uv；使用 stdio。

SIREN/SIRET 查询需要 INSEE_API_KEY，但高级企业搜索不需要。MIT 许可通过 README 徽章声明；未找到独立的许可证文本。源码针对 Sirene 3.11；当前 API 兼容性未经核实。

Recherche d'Entreprises MCP

源码安装（Source installation），需要 Node.js 18+，运行 npm install 和 npm run build；使用 stdio。其公开的企业搜索请求不使用凭证（credentials）。ISC 许可在包元数据（package metadata）中声明。README 包含一个占位符的克隆 URL：应使用规范的仓库链接。

McpDiffusion

Beta 项目，不是官方支持的 INSEE 产品。文档化了一个公开 HTTP 端点；大多数自托管工具需要私有的 Elasticsearch 索引，而只有 RMES SPARQL 工具可以在没有它的情况下工作。

Geocontext

IGNfab 孵化期原型（incubation prototype），提供远程 HTTP 和本地 stdio 选项。该项目明确声明它还不是一款工业化的 IGN 产品。

VosDroits MCP

社区版 Go 服务器，以二进制文件和 Docker 镜像形式分发，通过 stdio 运行。它通过网页抓取（web scraping）而非官方 API 来获取 Service-Public 和税务方面的官方内容。

france-data-mcp

提供一个托管的 Streamable HTTP 端点，以及一个 npm stdio 封装，覆盖 13 个公开数据源和 36 个工具。公开端点文档化了按 IP 速率限制（per-IP rate limit）。

France Travail MCP

本地 stdio 服务器，需要免费的 France Travail 应用程序凭证（application credentials）以及所使用 API 的订阅。La Bonne Boîte（译注：法国求职机构 France Travail 旗下的"优质雇主"推荐服务）需要单独审批，默认处于禁用状态。

sncf-mcp

本地 Go 服务器，默认使用 stdio，需要一个免费的 SNCF/Navitia API 密钥。它涵盖行程规划和运营信息，但不提供票价信息。
