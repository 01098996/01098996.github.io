远程 MCP 服务器

远程 MCP（Model Context Protocol，模型上下文协议）服务器是由他人替你运行的 MCP 服务器。你不需要安装包、通过 stdio（标准输入输出）启动本地进程，而是让客户端指向一个 URL 并完成认证，通常使用 OAuth。

| | 本地服务器 | 远程服务器 |
|---|---|---|
| 分发方式 | npm（Node 包管理器）、PyPI（Python 包索引）、Docker、二进制文件 | 一个 URL |
| 传输方式 | stdio | Streamable HTTP（或旧版 SSE（Server-Sent Events，服务器推送事件）） |
| 运行位置 | 你的机器 | 服务商的基础设施 |
| 认证方式 | 环境变量（env vars）、配置文件 | OAuth，或 API key（应用程序编程接口密钥） |
| 更新方式 | 你自己升级 | 服务商发布 |此处列出的全部都是远程服务器。只有在端点成功响应 MCP initialize 握手之后，条目才会被收录。

如何连接

大多数客户端接受一个裸 URL。几个示例：

Claude Code

claude mcp add --transport http linear https://mcp.linear.app/mcp

mcp.json（Cursor、VS Code 以及其他读取此格式的客户端）

{"mcpServers": {"linear": {"url": "https://mcp.linear.app/mcp"}}}

Claude.ai / ChatGPT，在 Settings → Connectors 下添加 URL。

对于 🔐 OAuth 服务器，客户端会在首次使用时打开浏览器窗口。对于 🔑 服务器，你需要提供一个令牌（token），通常以 Authorization: Bearer <token> 请求头的形式发送。
