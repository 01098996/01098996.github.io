rizqinrr/viserys-agent

Viserys 是一个自包含的 Markdown 工作流（workflow）、审查者人设（persona）以及校验脚本的合集。它让智能体在完整的开发生命周期中始终遵循一套一致的流程，而不是每遇到一个任务就即兴发挥。

DEFINE -> PLAN -> BUILD -> VERIFY -> REVIEW -> SHIP

在 OpenCode 中使用 Viserys 模式

本仓库在 .opencode/agent/viserys.md 中内置了一份 OpenCode 智能体定义，并通过 .opencode/opencode.json 注册其技能。

激活方式如下：

1. 克隆本仓库。

2. 用 OpenCode 打开仓库所在目录。

3. 按下 Tab 键，选择 viserys。
