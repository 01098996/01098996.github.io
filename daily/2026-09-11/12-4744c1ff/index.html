# PCB skill

一个智能体技能，能把硬件想法一路带到可下单、可焊接、可点亮的电路板。覆盖概念、原理图、采购、布局、布线、验证，外加停在付款前页面的下单准备。

它跑在 Claude Code（桌面版）或 Codex（桌面版）里，通过 MCP（Model Context Protocol，模型上下文协议）驱动 EasyEDA Pro，采购则在已经登录的浏览器里完成。

这不是一篇 PCB 理论的教程。它是一组关卡，专门抓理论抓不到的问题。比如旋转了 180° 的连接器让显示屏永远插不进去，比如藏在模块下方的电容，比如只存在于绘图图层的禁布区，再比如一个检查器在悄悄测量上一个版本。每条规则都是在一块真实电路板上付过代价的。详见 docs/case-study.md。

## 三条原则

**性价比（cost-effectiveness）** 每个器件都从实时页面报价，或者老老实实标成估算。BOM（物料清单，Bill of Materials）会和你已有的库存做净额核对。

**好装配（assemblable by hand）** 你就是装配工人，不采用底部端子封装（bottom-terminated package），每个焊盘都够得着，焊接顺序也不会把哪个接头封死。

**免费 PCB** 从最初草图开始，就把原型设计控制在免费打样（free-prototype）的额度里，而不是等到最后。

## 安装

SKILL.md 会把 references/、scripts/ 和 setup/ 作为同级目录加载，三个都得落到技能目录里。本仓库把 scripts/ 和 setup/ 放在顶层，这样在仓库里浏览起来更方便。只复制 skills/pcb/ 的话，得到的技能会缺检查器和安装指南。

bash
git clone https://github.com/daishuge/pcb-skill.git
cd pcb-skill
DEST=~/.claude/skills/pcb # Codex: DEST=~/.codex/skills/pcb
mkdir -p "$DEST" && cp -R skills/pcb/. scripts setup "$DEST"/
# verify — a missing directory here fails later, in the middle of a design
ls "$DEST"/SKILL.md "$DEST"/references "$DEST"/scripts "$DEST"/setup > /dev/null && echo "pcb installed"

然后照着 setup/README.md 走一遍。技能在启动前会检查下面这些。

- EasyEDA Pro 加 MCP 桥接，详见 setup/easyeda-mcp.md
- 装好智能体扩展的浏览器，并已经登录你的 PCB 厂商和器件供应商，详见 setup/browser-logins.md
- 一个权限确认观察器，桌面每次浏览器动作都弹权限卡时才需要，详见 setup/auto-approve-macos.md 和 setup/auto-approve-windows.md

购物车和支付始终保持人工操作，观察器从不去碰。

## 工作流程

| 阶段 | 产出 | 关卡 |
|---|---|---|
| 1 概念 | 已对齐的硬约束与软约束 | 凡是两种答案会导向不同板子的提问，都已经问过了 |
| 2 原理图 + 采购 | 原理图、已报价的 BOM、暂存的购物车 | 网表（netlist）断言通过；每个价格都已 VERIFIED（已核实）或标注 ESTIMATE（估算） |
| 3 布局 + 布线 | 已放置、已布线、已铺铜 | 布局能走通线，不是只满足合法性；DRC（Design Rule Check，设计规则检查）干净；对抗性审查通过 |
| 4 制造 + 下单 | 已核实的 Gerber 文件，订单停留在付款前页面 | 文件包独立于生成它的工具进行了验证 |

智能体从不提交订单，也从不付款。它只负责一路推进到付款前页面，把「点击付款」交给你。

## 四条立功的规则

**亮绿灯不等于板子做对了。**

每个阶段都以一次性的只读对抗性审查收尾。它会重新推导各项数值，而不是直接读取。终止准则要在启动前就写好，否则审查会陷入死循环。

**要测量，不要推断。**

「这大概不支持」不是结论。如果某个断言会决定工作是否继续，就得证明它，并说清楚哪些数值是测量得到的、哪些是计算得到的。

**先验证工具，再看结果。**

参考项目上有三个检查器，曾静悄悄地量错了东西。

用已知的非对称物体去校准每一个几何变换。

等待条件必须能回答一个问题。如果此刻程序崩溃，过滤器会不会吐出一行？参考项目上的一次运行沉默了 10 小时 53 分，答案是不吐。
