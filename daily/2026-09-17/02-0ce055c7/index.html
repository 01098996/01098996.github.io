agent-isles 仍处于早期开发阶段。目前提供本地 Web MVP（Minimum Viable Product，最小可行产品）以及 Windows x64 启动器/打包预览版；macOS Intel 与 Apple Silicon 的便携版构建已实现，但尚未发布。安装与构建细节请参见桌面启动器指南。

Windows 便携预览版：把整个 ZIP 解压到一个较短的路径，然后运行 agent-isles.exe。首次使用时需要配置模型（model）。用户数据保存在 %LOCALAPPDATA%\agent-isles\data；可以通过系统托盘菜单停止服务。该预览版未签名，也没有自动更新功能。请先退出旧版本，再把更新包解压到一个新目录，不要直接覆盖正在使用的文件。

What is agent-isles?

agent-isles 是一个用于学习与创作的 AI 编程可探索环境。它把通常藏在聊天框、终端和工具列表背后的 Agent 能力，转化为一座岛屿世界中的伙伴、地点和行动。你可以从一个想法出发，借助 AI 把它做成一个真正可运行的项目，而无需先掌握模型（model）、会话（session）、工具调用（tool call）或仓库结构。

在完成首个项目的过程中，你可以选择引导式学习，来了解需求、项目、执行、审批与验证；或者选择自由创作，连接已有项目，按自己的节奏探索。学习不脱离实际工作，也不会被拆成一门独立课程：AI 可以行动，而你依然负责提出想法、亲身体验、做出判断并持续打磨结果。

这座可探索的世界让 AI 编程的初次接触不再那么令人畏惧，同时也不会掩盖它真实的能力与责任。任务状态会反映在世界和它的居民身上，而文件、对话历史与项目都有清晰的入口。当你需要更多细节时，高级工作台会展示完整的对话、工具调用以及人工审批流程。

在 Windows 上，已安装的预览版会启动服务，并通过 agent-isles 快捷方式打开小岛，运行时和资源都已包含在内。源码构建仍然可以使用 打开小岛.cmd 来打开一个已经在运行的开发服务；该脚本并不是已安装应用的入口。（译注：脚本文件名直接使用了中文"打开小岛"，是项目自带的命名习惯。）

Main features

Workbench

Available now：连接真实的本地项目、与 AI 对话、检查文件和工具调用、处理审批，并继续使用已有的工作区（workspace）和会话（session）。

Education and guidance

Planned：把需求、项目选择、执行、审批与验证，转化为面向 AI 编程新手的渐进式学习路径。

More islands

Planned：扩展群岛，加入不同的地点、居民与主题，让不同项目能力拥有各自的性格与归宿。

Richer ways to play

Planned：通过更多互动和发现，把任务进度、居民关系、探索行为和最终成果串联起来，同时不牺牲真实的工作流。

Quick start

Requirements

- Windows 或 macOS Intel / Apple Silicon，用于源码开发；便携预览版要求请参见桌面启动器指南
- Node.js ^22.19.0 或 >=24.0.0
- Corepack
- 支持子模块（submodule）的 Git
- 导出世界时需要 Godot 4.7.2 及其 Web 导出模板，或配置好的 GODOT_BIN

Start the local Web app

在仓库根目录运行以下命令：

corepack enable
corepack yarn install immutable
corepack yarn dev:web no open

打开终端中打印的本地 URL。首次使用时，按界面提示配置模型并选择一个本地项目目录，然后与某位居民对话。

开发数据默认保存在仓库内的 .agent-isles-home/。若想使用其他位置，需在启动前设置 DSH_HOME。

Local project

Godot 负责渲染世界与居民状态。React 提供工作区选择与居民交互面板。DeepSeek Harness 仍是对话与执行状态的唯一真实来源（single source of truth）。agent-isles 通过公开的 DSH/Cordis 插件接口（plugin interface）进行集成，既不修改上游源代码，也不会在外面再裹一层会话 API。

Upstream and versioning

当前稳定渠道固定在 DeepSeek Harness 0.1.3-alpha.1，commit 为 d347e703908d0406b7a7ef80e3a0e594d86b2215。版本和运行时产物记录在 upstream.json 中。

- 不要直接修改 deepseek-harness/。
- 升级运行时前，请先更新固定版本，再运行兼容性验证。
- 将 agent-isles 的产品逻辑保留在其自身的插件和世界代码中。

Current limitations

- 文件管理员的只读行为目前是通过应用边界与提示（prompting）来强制执行的，并非完整的硬性权限边界。
- 文件管理员目前还不能编辑文件、预览图片、访问远程文件系统，也无法显示来自父仓库的变更。
- 完整的首节课程尚未在真实模型下完成端到端验证；真实任务、恢复路径与教学节奏仍需验证。
- 面板支持移动端布局，但世界中的控件仍主要面向键鼠设计。
- 通知仅存储在当前浏览器中，既不会跨浏览器同步，也不会使用操作系统的通知能力。
- 最新的 Windows 安装包尚未重新构建并验证安装、卸载与真实任务流程。预览构建未签名；自动更新和发布渠道尚未实现。
