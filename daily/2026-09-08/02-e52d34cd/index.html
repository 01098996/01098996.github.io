GPT-6 Astra

GPT-6 Astra 「今日起开始向一部分机构推出，未来几天内将面向所有 ChatGPT Plus、Pro、Business 和 Enterprise 用户开放，也能通过 OpenAI API 和 AWS 调用」。我自己还没用过，暂时也说不上太多。API 定价跟 Claude Fable 5 和 5.1 持平，输入 10 美元/百万 tokens，输出 50 美元/百万 tokens。这显然是 OpenAI 对标 Fable 的产品，在 OpenAI 自家公布的大多数基准测试上得分都比 Fable 高。

最惊艳的一点是，Astra 在今年 3 月发布的 ARC-AGI 3 基准测试上拿下了 99.9%。不过要交代一句，Fable 5 还没公布过成绩，而且 ARC-AGI 的博客提到，这个 99.9% 是 OpenAI 用自家的「Provider Adapter 工具链（harness）」花 1.9 万美元成本跑出来的；默认的 ARC-AGI 工具链只拿到 62.7%，成本 2.6 万美元。Provider Adapter 工具链会在多次请求之间保留不透明的推理状态（reasoning state），较长的对话则用压缩（compaction）来处理，让模型能复用之前的工作。

有了 Hugging Face 那档子事先垫着，Astra 在安全任务上猛也就合情合理了。ExploitBench 上拿下 100%（GPT-5.6 Sol 是 78.5%），ExploitGym 是 42.4%（Sol 是 30.3%），SRE-Bench 二进制逆向工程任务里四次尝试内 99.2%，Sol 是 68.7%。长上下文（long context）它也更拿手，OpenAI 的八针（eight-needle）基准测试里，256K 到 512K tokens 达到 100%，512K 到 1M tokens 是 96.3%。长上下文处理这块长期困扰大家的老大难，OpenAI 很可能已经拿下了。

但它也不是样样都能赢。Artificial Analysis 提到，他们的智能指数（Intelligence Index）上 Astra 还是打不过 Fable。智能水平上跟 GPT-5.6 Sol 并肩，GPT-6 Astra 在该指数上 61 分，跟 GPT-5.6 Sol 持平。这比 Claude Fable 5.1（开启 fallback 时的最高分）低 5 分，也落后于 Meta 刚发布的 Muse Spark 1.3（最高分）。不过在他们的编码智能体指数（Coding Agent Index）性价比前沿上，Astra 处于领跑位置。最大算力档（max effort）下，GPT-6 Astra 的成本跟 GPT-5.6 Sol（最高档）相当，指数上却高出 2 分。按单个任务算，成本不到 Claude Fable 5 的一半，得分却一样。

等我拿到权限再细聊 Astra。正式上线后，API 里的模型名称（model label）是 gpt-6-astra。
