GPT‑6 Astra

GPT-6 Astra 「今天开始向一部分组织推出，未来几天将面向所有 ChatGPT Plus、Pro、Business 和 Enterprise 用户开放，也可以通过 OpenAI API 和 AWS 使用」。我自己还没试用过，暂时没什么好多说的。

API 定价和 Claude Fable 5、5.1 一样，输入每百万 token 10 美元，输出每百万 token 50 美元。这就是 OpenAI 拿来跟 Fable 竞争的产品。OpenAI 自己公布的大多数基准测试上，得分都比 Fable 高。

最猛的是 Astra 在今年 3 月发布的 ARC-AGI 3 基准上跑出了 99.9%。不过 Fable 5 暂时还没公布成绩。ARC-AGI 博客提到，这个 99.9% 是用 OpenAI 自定义的「Provider Adapter harness」花了 19,000 美元跑出来的；默认的 ARC-AGI harness 花了 26,000 美元，只拿到 62.7%。Provider Adapter harness 会在请求之间保留不透明的推理状态（opaque reasoning state），长对话时还会做压缩（compaction），让模型能复用之前的工作。

有 Hugging Face 事件在先，Astra 在安全任务上这么猛也就不奇怪了。ExploitBench 上 100%，GPT-5.6 Sol 才 78.5%；ExploitGym 上 42.4%，Sol 是 30.3%；SRE-Bench 二进制逆向工程四次尝试内 99.2%，Sol 只有 68.7%。长上下文（long context）方面也更强，OpenAI 的 eight-needle 基准里，256K 到 512K token 跑出 100%，512K 到 1M token 还有 96.3%。长上下文处理的一个长期难题，OpenAI 这次可能真给解决了。

不过它也不是什么都赢。Artificial Analysis 提到，他们的 Intelligence Index 上 Astra 还是被 Fable 压着。和 GPT-5.6 Sol 并列 61 分，比 Claude Fable 5.1（启用 fallback 的最高分）低 5 分，也落后于 Meta 新出的 Muse Spark 1.3（最高分）。

但在 Coding Agent Index 上表现更好。最大努力（max effort）设置下，GPT-6 Astra 的成本和 GPT-5.6 Sol（max）差不多，指数得分却高 2 分。按每个任务算，相同得分下成本还不到 Claude Fable 5 的一半。

等我有访问权限再细聊。API 模型标识符（model label）正式开放后会是 gpt-6-astra。
