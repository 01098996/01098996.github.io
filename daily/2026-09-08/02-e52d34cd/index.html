GPT‑6 Astra

GPT‑6 Astra 正在「今日起向部分机构开放，并在未来几天内逐步覆盖所有 ChatGPT Plus、Pro、Business 和 Enterprise 用户，同时也会通过 OpenAI API 和 AWS 提供服务」。我本人还没试用，所以暂时也说不出太多。

API 定价和 Claude Fable 5、5.1 一样，输入 10 美元/百万 token，输出 50 美元/百万 token。这明显是 OpenAI 对标 Fable 的产品，并且在 OpenAI 自家公布的大多数基准测试上得分高于 Fable。

最惊艳的一点是，Astra 在三月份发布的 ARC‑AGI 3 基准上拿到了 99.9%。不过 Fable 5 目前还没有公开成绩，而且 ARC‑AGI 博客里提到，这个 99.9% 是借助 OpenAI 自研的「Provider Adapter harness」（Provider Adapter 框架）花 19,000 美元跑出来的；用默认的 ARC‑AGI 框架则只有 62.7%，花 26,000 美元。Provider Adapter 框架会在请求之间保留不透明的推理状态（reasoning state），长对话时还会做压缩（compaction），让模型复用之前的工作。

考虑到最近的 Hugging Face 事件，Astra 在安全任务上这么能打也就不意外了。ExploitBench 上 100% 满分（GPT‑5.6 Sol 才 78.5%），ExploitGym 42.4%（Sol 30.3%），SRE‑Bench 二进制逆向工程四次以内 99.2%，Sol 68.7%。长上下文也更猛，在 OpenAI 的八针检索基准（eight‑needle benchmark）上，256K–512K token 区间 100%，512K–1M token 区间 96.3%。OpenAI 或许真的攻克了长上下文处理的一个长期难题。

不过也不是全胜。Artificial Analysis 指出，他们的智能指数（Intelligence Index）上 Astra 还是被 Fable 压一头。在该指数上 GPT‑6 Astra 和 GPT‑5.6 Sol 并列，都是 61 分，比 Claude Fable 5.1（开启 fallback 时的最高分）低 5 分，也落后于 Meta 刚发布的 Muse Spark 1.3（最高档）。

但在编程代理指数（Coding Agent Index）上 Astra 反超了，它领跑了这个指数的成本效率前沿。最大推理档位（max effort）下，GPT‑6 Astra 的成本和 GPT‑5.6 Sol（最大档）差不多，指数得分却高了 2 分。按单次任务算，成本不到 Claude Fable 5 的一半，得分却相同。

等我用上 Astra 之后再细聊。正式上线后 API 模型名是 gpt-6-astra。来自 Hacker News。
