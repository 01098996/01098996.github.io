今天，我们在最新的 Gemini 3.7 Flash、3.6 Flash 和 3.5 Flash-Lite 模型上正式推出智能体视频理解能力。它在显著降低视频分析 token 用量和成本的同时，准确率也往上走了。

这和智能体视觉（agentic vision）思路类似。后者把代码执行和 Gemini 原生的图像理解结合在一起，前者则用上了 Gemini 原生的视频工具。同样是为了提升性能、解锁新的视频处理能力，比如亚秒级关键时刻检索、更准的异常检测、精确计数，等等。

该功能今天起在 Google AI Studio 和 Gemini Enterprise Agent Platform 的 Gemini API 上可用，支持视频上传和 YouTube 视频。

基准测试

现在的做法是「静态」处理，模型按固定的每秒帧数（FPS，默认 1 FPS，可以通过 API 调整）把视频一口气吞下去。智能体视频理解不一样，它把模型的核心推理和原生视频工具组合起来，可以在画面帧、音频、转录文本之间动态搜索、扫描和检查目标片段。

标准视频分析基准测试显示，用上智能体视频理解的 Gemini 模型，分析成本最多降低 66%，token 消耗最多降低 88%，准确率最多还能再涨 7%。

长视频上的收益尤其明显，从 10 分钟的教程、90 分钟的讲座到几个小时的录播都算。因为静态处理下，开发者只能在高 token 成本和丢失关键细节的处理技巧之间二选一。

开智能体视频理解后，Gemini 3.7 Flash 的 token 消耗最多砍 88%，准确率最多涨 7%。

三款支持的模型都有提升，但开了智能体视频理解的 Gemini 3.7 Flash 整体质量最好，质量与成本效率的组合也最强，处于本次测试视频理解模型的准确率-成本帕累托前沿（Pareto frontier，译注：源自经济学中的帕累托最优概念，在 AI 评测中常用来描述「性价比」难以同时进一步提升的临界曲线）。

开了智能体视频理解之后，Gemini 3.7 Flash 就站在了视频分析的准确率-成本帕累托前沿上。

工作原理

静态处理按固定帧率把媒体流吞下去。智能体视频理解不一样，Gemini 变成了一个主动的、有目标的观察者。它自己决定看哪里、看多快、用哪种模态（帧、音频还是转录文本），只抓真正需要的那一瞬间和信号。以前开发者也能手动做这件事，但得自己写不少逻辑。现在 Gemini 能在智能体循环（agentic loop）里自己搞定，它会调用内部工具去加载视频的相关段落，开发开销一下子小了很多。

能力与应用场景

智能体视频理解改变了开发者处理长视频内容的方式，各种要求高的场景都能用上。

亚秒级关键时刻检索（sub-second moment retrieval）。在 1 FPS 下容易漏掉的分秒级状态变化和紧凑的剪辑边界，现在都能精准定位，自动化视频剪辑终于能做精细活了。

长视频大海捞针式检索（needle-in-a-haystack search）。几小时长的视频，不用烧掉上百万 token，也能回答复杂问题。

异常检测（anomaly detection）。对感兴趣的时间窗口用更高 FPS 重采样，专门检查快速运动和细微的视觉瑕疵。

动作与物体计数（counting action & object）。随时间精确追踪重复的物理动作和不同的物体。

上手

智能体视频理解在 Google AI Studio 和 Gemini Enterprise Agent Platform 的 Gemini API 上可用，覆盖 Gemini 3.7 Flash、3.6 Flash 和 3.5 Flash-Lite。沿用标准 Gemini API token 定价，不收额外功能费。

想启用它，在 API 配置里把 processing 设为「agentic」就行。更多信息和上手方法可以看开发者指南。

from google import genai

client = genai.Client()

interaction = client.interactions.create(
    model="gemini-3.7-flash",
    input=[
        {
            "type": "video",
            "uri": "https://youtu.be/7Z5Vy9JBANs",
            "processing": "agentic"
        },
        {
            "type": "text",
            "text": "What are the 3 most important announcements in this keynote?",
        },
    ],
)

print(interaction.output_text)
