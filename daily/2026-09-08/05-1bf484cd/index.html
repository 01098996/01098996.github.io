推出基于 Gemini 的智能体视频理解能力

Google 刚刚在 Gemini 3.7 Flash、3.6 Flash 和 3.5 Flash-Lite 上线了智能体视频理解（agentic video understanding）。模型可以动态扫描视频片段（video segments），准确率往上提，token 用量最多砍 88%，成本最多省 66%。想上手的话今天就行，去 Google AI Studio 或 Gemini Enterprise Agent Platform 里把 API 配置（API configuration）设成「agentic」就够了。

今天，我们在最新的几款模型上正式推出智能体视频理解，覆盖 Gemini 3.7 Flash、3.6 Flash 和 3.5 Flash-Lite。这个新能力一边把视频分析的 token 用量和成本砍下来，一边把准确率往上推。它和智能体视觉（agentic vision）走的是同一条路，后者把代码执行和 Gemini 模型原生的图像理解拼到了一起；智能体视频理解则是用上 Gemini 原生的视频工具来提性能，顺带解锁了一批新能力，比如亚秒级的关键时刻检索、更准的异常检测、精确计数等等。

该功能从今天起，通过 Google AI Studio 和 Gemini Enterprise Agent Platform 中的 Gemini API，面向视频上传和 YouTube 视频开放。

基准测试

现在的静态（static）处理是按固定帧率把视频一口吞进模型，默认 1 FPS，可通过 API 调。智能体视频理解走的是另一条路，它把模型的核心推理和原生视频工具绑在一起，在视觉帧、音频、转录文本（transcript）之间动态搜索、扫描、定位目标片段。在标准视频分析基准测试里，开了智能体视频理解的 Gemini 模型，分析成本最多降 66%，token 消耗最多省 88%，准确率最多提 7%。

长视频场景里这个收益格外明显，从 10 分钟的教程、90 分钟的讲座，到好几个小时的录播都算。静态处理在这种场景下逼着开发者在两件事之间二选一，要么承受高额 token 成本，要么用一些会丢掉关键细节的处理技巧。

把智能体视频理解打开之后，Gemini 3.7 Flash 的 token 消耗最多降 88%，准确率最多涨 7%。

三个支持模型都能拿到这些提升，但 Gemini 3.7 Flash 配合智能体视频理解拿到的整体质量最高，质量与成本效率的组合也最均衡。在参与测试的视频理解模型里，它就站在准确率与成本的帕累托前沿（pareto frontier）上。

工作原理

静态处理是模型按固定帧率一口吞下整个媒体流。智能体视频理解换了个玩法，Gemini 主动出击、以目标为导向（goal-directed），自己决定看什么、看多快、走哪条模态（modality，即帧、音频还是转录文本），按需抓取最相关的瞬间和信号。以前开发者也能手搓这套流程，但现在 Gemini 自己就能在一个智能体循环（agentic loop）里搞定，调内部工具把视频里相关的片段加载进来，开发开销一下小了很多。

能力与应用场景

智能体视频理解改变了开发者处理长视频内容的方式，覆盖一批高要求的应用场景。

亚秒级关键时刻检索（Sub-second moment retrieval）
精确定位转瞬即逝的状态变化和紧凑的剪辑切点，1 FPS 下很容易漏掉，让精准的自动化视频剪辑成为可能。

长视频大海捞针式检索（Long-form needle-in-a-haystack search）
在长达数小时的视频里回答复杂查询，不用烧掉数百万 token。

异常检测（Anomaly detection）
对感兴趣的时间窗口按更高 FPS 重采样（resample），捕捉快速运动和细微的视觉瑕疵。

动作与物体计数（Counting action & object）
精准跟踪反复出现的物理动作和不重样的物体。

],

)

print(interaction.output_text)
