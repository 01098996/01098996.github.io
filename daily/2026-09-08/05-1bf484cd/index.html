推出 Gemini 的智能体视频理解（agentic video understanding）能力

Google 刚刚为 Gemini 3.7 Flash、3.6 Flash 和 3.5 Flash-Lite 推出了智能体视频理解。这个功能让模型动态扫描视频片段，准确率更高，token 用量最多砍 88%，成本最多降 66%。今天就能用，在 Google AI Studio 或 Gemini Enterprise Agent Platform 里把 API 配置改成「agentic」就行。

今天，我们在最新的三款模型 Gemini 3.7 Flash、3.6 Flash、3.5 Flash-Lite 上全面上线了智能体视频理解。这项新能力在大幅压缩视频分析 token 用量和成本的同时，准确率还能往上提。思路和我们之前做的智能体视觉（agentic vision）类似，那个是把代码执行（code execution）和 Gemini 的原生图像理解能力结合起来。智能体视频理解则是调用 Gemini 原生的视频工具来提升表现，解锁了一批新能力，比如亚秒级时刻检索、更准确的异常检测、精确计数等等。

功能今天就能用，通过 Gemini API 接入 Google AI Studio 和 Gemini Enterprise Agent Platform，支持视频上传和 YouTube 视频。

基准测试

传统处理方式是「静态」的，模型按固定帧率（frames-per-second，默认 1 FPS，API 可调）往里灌。智能体视频理解换了一种打法，把模型的核心推理和原生视频工具串起来，能在视觉帧、音频、字幕之间动态搜索、扫描、定位目标片段。在标准视频分析基准测试上，开了智能体视频理解的 Gemini 模型，分析成本最多降 66%，token 消耗最多砍 88%，准确率最多涨 7%。

这种效率提升在长视频上尤其明显。从 10 分钟的教程，到 90 分钟的讲座，再到几个小时的录播，都算长视频。静态处理在这种场景下逼着开发者二选一，要么硬扛高昂的 token 成本，要么用一些会丢关键细节的技巧。

工作原理

静态处理是按固定帧率往模型里灌媒体流。智能体视频理解不一样，它让 Gemini 主动出击，以目标为导向地决定该看什么、以什么速度看、用哪种模态（modality，帧、音频、字幕都行）去看，只拉取它真正需要的那几段画面和信号。开发者以前也能手动做这件事，但有了智能体视频理解，Gemini 可以自己跑一个智能体循环（agentic loop），调内部工具把视频文件对应的部分加载进来，开发开销小了很多。

能力与应用场景

智能体视频理解改变了开发者处理长视频内容的方式，在各种高要求的应用场景下都能用上。

- 亚秒级时刻检索（sub-second moment retrieval）。精确定位瞬间的状态变化和紧凑的剪辑切换点，这些在 1 FPS 下很容易漏掉。有了它，自动化精确视频剪辑就变成了可能。
- 长视频大海捞针（needle-in-a-haystack search）。在长达数小时的视频里回答复杂问题，不用烧掉几百万 token。
- 异常检测（anomaly detection）。把感兴趣的时间窗口用更高 FPS 重采样（resample），仔细看快速运动和细微的视觉伪影（artifact）。
- 动作与目标计数（counting action & object）。在一段时间内准确追踪重复出现的物理动作和不同的物体。

入门指南

智能体视频理解走 Gemini API，可以在 Google AI Studio 和 Gemini Enterprise Agent Platform 上用，覆盖 Gemini 3.7 Flash、3.6 Flash、3.5 Flash-Lite 三款模型。定价按 Gemini API 的标准 token 价格走，不额外收功能费。

启用方法很简单，在 API 配置里把 processing 设为「agentic」就行。想了解更多细节和上手步骤，可以看看我们的开发者指南。

from google import genai

client = genai.Client()

interaction = client.interactions.create(

  model="gemini-3.7-flash",

  input=[

    {

      "type": "video",

      "uri": "https://youtu.be/7Z5Vy9JBANs",

      "processing": "agentic"

    },

    {

      "type": "text",

      "text": "What are the 3 most important announcements in this keynote?",

    },

  ],

)

print(interaction.output_text)
