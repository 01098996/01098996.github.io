50美元24小时：AI代理如何意外拿到60%回复率

我给一个 AI 智能体 50 美元和 24 小时，让它去预约会议线索。结果它把 40 位创始人怼了一遍，回复率冲到 60%，还赚了 600 美元。

身边一堆人在聊复杂的智能体工作流（agentic workflows）、多智能体集群（multi-agent swarms），还有记忆层（memory layers）。昨天我搞了个挺蠢的实验，就想测一下最基本的循环执行和状态追踪能不能跑通。

我搭了个轻量级的智能体，让它去 Twitter 和 Reddit 上找那些发帖抱怨扩容问题的 SaaS 创始人。找到了就给人家发一条简短实用的私信（DM），提议做个 15 分钟的快速审计。我给了它 50 美元的 API 预算，然后就放手让它自己跑。

它压根没用我给的那套礼貌正式的企业冷联系模板。跑到大概 15 轮的时候，一次提示词泄漏加上上下文截断（context-truncation）的 bug，把那条「专业语气」的系统提示词搞丢了。

然后它开始直接扒创始人的公开代码仓库和落地页（landing page），写出来的东西是那种残忍直白、两句一组的硬核点评，根本不是销售话术。比如这样的

「你的落地页首屏加载要 4 秒，行动号召按钮（CTA）埋在没人会读的三段文字下面。先把这个改了，再去买广告。」

「你在卖多智能体框架，但你的 GitHub 仓库零单元测试，还挂着 3 个未修复的安全漏洞。」

第二天醒来，我本以为会看到 API 密钥被吊销，或者满屏的封号通知。但跑出来的数据完全是另一个画面

- 回复率 62%，冷私信一般也就 2% 到 5%。
- 8 位创始人回了一句：「扎心了，但你说得对，你真能修吗？」
- 今天成交了 2 单快速审计，每单 300 美元。

我们花太多时间在搭复杂的护栏，还有那种极度礼貌的企业人设智能体上。但在智能体时代，高针对性的实用价值和零废话的分析，每次都跑赢礼貌的营销话术。
