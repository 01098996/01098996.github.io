GPT‑6 Astra

GPT-6 Astra "正在向部分组织（organization）开放（rolling out），未来几天将面向所有 ChatGPT Plus、Pro、Business 与 Enterprise 用户开放，同时也会通过 OpenAI API 以及 AWS 提供"，我自己还没试用过，所以暂时没什么好说的。它的 API 定价与 Claude Fable 5 和 5.1 持平：输入 $10/百万 token，输出 $50/百万 token。这显然是 OpenAI 用来对标 Fable 的产品，并且在 OpenAI 自家报告的大多数基准（benchmark）上得分高于 Fable。

最令人印象深刻的是，Astra 在今年 3 月发布的 ARC-AGI 3 基准上拿到了 99.9% 的成绩，不过需要指出的是，Fable 5 目前还没有公布结果；ARC-AGI 博客也注明，99.9% 的成绩是借助 OpenAI 自家的"Provider Adapter harness"（Provider Adapter 评测框架）以 $19K 的成本取得的，而默认 ARC-AGI 评测框架下得分仅为 62.7%，成本 $26K。Provider Adapter 评测框架会在多次请求之间保留不透明的推理状态（reasoning state），并对较长对话使用上下文压缩（compaction），从而让模型复用先前已完成的工作。

考虑到最近发生的 Hugging Face 事件（译注：Hugging Face 平台此前被曝出遭恶意利用的安全事件），Astra 在安全任务上表现出色也就不足为奇了。它在 ExploitBench 上拿到 100%（GPT-5.6 Sol 为 78.5%），在 ExploitGym 上为 42.4%（Sol 为 30.3%），在 SRE-Bench 二进制逆向工程任务上四次以内尝试的得分为 99.2%，而 Sol 为 68.7%。它在长上下文（long context）方面也更胜一筹：在 OpenAI 的 eight-needle 基准上，256K–512K token 区间取得 100%，512K–1M token 区间取得 96.3%。OpenAI 或许已经攻克了长上下文处理领域的某个长期难题。

不过它也不是在所有项目上都胜出。Artificial Analysis 指出，在他们自家的 Intelligence Index（智能指数）上 Astra 仍然不敌 Fable：与 GPT-5.6 Sol 的智能水平相当，GPT-6 Astra 在该指数上得分为 61，与 GPT-5.6 Sol 持平。这比 Claude Fable 5.1（启用 fallback 的最高档）低了 5 分。该模型同样落后于 Meta 新发布的 Muse Spark 1.3（最高档）。不过它在 Coding Agent Index（编程 Agent 指数）上表现更好：在最大算力（max effort）档位下领跑该指数的成本效率前沿（cost efficiency frontier）；GPT-6 Astra 的成本与 GPT-5.6 Sol（最大算力档）大致相当，但在该指数上高出 2 分。按单任务计算，该模型的成本不到 Claude Fable 5 的一半，却能取得相同的得分。

等我拿到访问权限后，会再写一些关于 Astra 的内容。该模型在 API 上线后对应的模型标签（model label）为 gpt-6-astra。
