yukitorido/short-video-generator-AI

一个免费的开源项目，专门把 YouTube 视频剪成能火的短视频。高光检测、字幕、翻译、配音，一套流程搞定。不会在片头加出处标注，也不带任何水印。给那些想找 OpusClip、Vidyo.ai 这类短视频 SaaS（Software as a Service，软件即服务）工具免费替代品的创作者用。

处理好的视频示例

> 「The Speech that Made Obama President」
>
> 「How Tom Overcame Social Anxiety - The Mindset That Changed Everything」
>
> 「How to stay calm when you know you'll be stressed | Daniel Levitin | TED」

功能

- API，可以把它接到自己的项目里，通过我们的应用程序编程接口（API）自由调用这个生成器。
- 省事，粘贴一个 YouTube 链接（不管多长都行），就能拿到一条可以直接发的 9:16 竖屏短视频。
- 钩子选项，开启后会在片段开头加一段 AI 根据上下文生成的钩子。
- Web 版本，除了命令行界面（CLI），也可以在本地网页上生成视频。
- 智能高光，按算法自动挑出视频里最可能爆的热门片段。

工作原理

- 抓源视频，从 YouTube 拉视频，或者直接用本地文件路径。
- 转写，用 faster-whisper 在本地生成带时间戳的转写文本。不管最后用哪家 LLM_PROVIDER，这一步都一样。
- 判断内容类型，选定的 LLM 会给视频分类（播客、采访、教程、Vlog 等），顺便判断节奏。这样高光提示词就能按不同内容风格调优。
- 高光排序，选定的 LLM（openai/gemini/muapi）会按一套爆款框架扫描转写文本，维度包括钩子时刻、情绪高峰、观点炸弹、真相揭露、冲突、金句、故事高潮、实用价值，然后输出带 0–100 分数的候选排序。
- 去重，把重叠的候选按分数合并掉。
- Top-N 选取，挑出排名前 --n 的候选。
- 自动裁剪，每个高光都会按指定的 --ratio 渲染成竖屏短视频。如果不设 --no-hook，开头还会加一段可选的 AI 生成钩子。

环境要求

- Python 3.10+
- 任一 LLM 的 API 密钥（OpenAI/Gemini/MuAPI）
- requirements.txt 里的依赖

快速开始

克隆仓库：

git clone https://github.com/yukitorido/short-video-generator-AI.git
cd short-video-generator-AI

创建并激活虚拟环境：

Windows：

python -m venv venv
venv\S cripts\a ctivate

Linux/MacOS：

python -m venv venv
venv\S cripts\a ctivate

安装依赖：

pip install -r requirements.txt

设置 .env：

#Used LLM provider(openai/gemini/MuAPI)
LLM_PROVIDER=openai

#Enter the API key for the chosen provider
OPENAI_API_KEY=your_openai_key_here
OPENAI_MODEL=gpt-4o-mini#optional

GEMINI_API_KEY=your_gemini_key_here
GEMINI_MODEL=gemini-2.5-flash#optional

MUAPI_API_KEY=your_muapi_key_here

#Whisper settings
LOCAL_WHISPER_MODEL=base#tiny / base / small / medium / large-v3
LOCAL_WHISPER_DEVICE=auto#auto / cpu / cuda

使用

基础用法：

python main.py "https://www.youtube.com/watch?v=video_id"

渲染好的片段会保存到 output 文件夹。

带参数：

python main.py "https://www.youtube.com/watch?v=video_id" --n 3 --ratio 9:16 --resolution 1080

也可以用本地视频文件代替 YouTube 链接，比如：

python main.py "/Users/Admin/Folder/video.mp4" --n 4 --ratio 9:16 --resolution 720 --language zh

CLI 参数

| 参数 | 默认值 | 说明 |
|---------------|------------------|--------------------------------------------|
| --n | | 要渲染的片段数 |
| --ratio | 9:16 | 任意比例 / 9:16 适合短视频 / 1:1 适合方形 |
| --resolution | 源视频下载分辨率 | |
| --language | auto | 强制指定 Whisper 语言代码（比如 en） |
| --no-hook | | 不在片段开头加 AI 生成的钩子 |
