Claude Code 2.1.277 更新：自动模式服务端分类器与 AGENTS.md 支持

Claude Code now reads AGENTS.md if there is no Claude.md

Claude Code 发布 2.1.277 版本，为 API 与企业用户在 Bedrock、Vertex、Foundry 等平台默认启用服务端分类器，自动模式不再收取分类器开销，可通过环境变量退出回退。同时新增 AGENTS.md 支持：项目无 CLAUDE.md 时改为读取 AGENTS.md，可在配置中修改，但暂未覆盖 Bedrock、Vertex 与 Foundry。

为什么读本次更新同时涉及计费逻辑变更和项目指令文件兼容策略，对在多平台上部署 Claude Code 的团队有直接影响。

带着问题读AGENTS.md 的识别逻辑是否会与已有 CLAUDE.md 的项目产生冲突，且何时会扩展到 Bedrock、Vertex 与 Foundry？

Repopilot：基于 Codex SDK 的验证驱动型 AI 软件迭代工具

Repopilot 是一个验证驱动的 AI 软件迭代工具，基于 OpenAI Codex SDK 构建。自托管代理可将目标、GitHub Issue 与 PR 反馈转化为经过测试、可审查的代码变更，限制执行范围，由人类控制合并与部署。

AI 大模型世界：把 556 个模型做成像素小人的可视化站点

liyupi/ai-model-world

AI 大模型世界是一个可视化站点，将 556 个大模型拟人化为像素小人，展示模型的智能、代码、价格与发布时间。提供国内外厂商分区、完整时间线与多维排行榜，数据源自 Epoch AI、models.dev、LiveBench 与 Hugging Face，每小时自动同步，采用 Next.js 静态导出零后端架构。

带着问题读「最聪明」「最会写代码」这类排序背后的具体指标和权重是什么，是否在站内有透明说明？
