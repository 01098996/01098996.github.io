按功能描述找代码：jevgrep CLI

dzhng/jevgrep

jevgrep 是一个面向编程代理的命令行工具，核心思路是用自然语言描述代码功能，再由 Jev 检索引擎在代码库中定位相关文件并提取源码上下文。它面向 Claude Code、Codex 等编程代理场景，作为外部检索层弥补模型对项目结构的不熟悉。★237，TypeScript 实现。

为什么读它把以意图搜代码的思路做成了 CLI，能直接挂接到编程代理的工作流中。

带着问题读Jev 相比 ripgrep 这类纯文本检索，是靠语义嵌入还是额外索引来提升召回？

一镜到底的运动影片：onetake Claude Skill

feitangyuan/onetake

onetake 是一个 Claude Agent Skill，专注生成不切镜头的连续动画影片：每一帧画面从前一帧过渡而来，整段保持同一虚拟机位，画面衔接由连续性判定 oracle 评估。它适合产品发布片和功能演示场景，能产出连贯的运动图形。★305，Python 实现。

为什么读它把连贯性作为一等约束交给 oracle 打分，而不是依赖抽卡式的随机生成。
