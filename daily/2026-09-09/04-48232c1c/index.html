GPT‑5.6 Sol 如何助力量子计算实验

把 GPT‑5.6 Sol 接入实验室软件，让它自己跑量子芯片上的常规测量并不断调优。Beatriz Yankelevich 这下腾出了手，可以专心做实验设计和数据分析。

量子计算还是一门新兴技术，靠的是量子力学那些独特的性质来处理信息。将来某天，它或许能更精确地模拟复杂的材料和分子。跟传统处理器不同，量子处理器是用量子比特（qubit）搭起来的。而准备和跑一次量子比特实验，往往就要花上几个月，还得做几百到几千次预测量。AI 正好可以在这种工作上帮上忙。

MIT 工程量子系统组（Engineering Quantum Systems Group, EQuS）的研究生 Beatriz Yankelevich 用上了 GPT‑5.6 Sol，再把 Codex 接进来，想试试 AI 能不能帮她简化实验流程。这个组研究的是超导量子比特（superconducting qubit），得用一种叫稀释制冷机（dilution refrigerator）的专用设备把它们冷却到接近绝对零度。这类量子比特运算速度快，靠微波信号就能精确控制，制造工艺也很成熟，可以直接做在芯片上。

超导量子比特芯片完成制备、封装、冷却之后，研究人员跟它所有的交互都得通过软件进行，Yankelevich 的实验天然成了 AI agent 的试验场。把 Codex 接到那套协调实验的实验室软件上，它就能自己跑测量、看结果，再决定下一步该试什么。Yankelevich 发现，GPT‑5.6 Sol 大多时候都能自主跑完常规的测量工作流，省下了她大把时间，实验也不用一直盯着。她终于能腾出更多精力来分析结果、设计实验、规划下一步的研究。

协调相互依赖的测量

超导量子比特常被叫做人造原子（artificial atom），因为跟真正的原子一样，它们也只能待在特定的能级上。微波脉冲（microwave pulse）可以在这些能级之间搬动量子比特，顺便探测它的量子态。研究人员设计并校准发往芯片的脉冲序列，再把返回的信号数字化、做分析。这些测量会揭示每个量子比特的共振频率（resonance frequency），让研究人员能精确控制它；也能测出量子比特保持量子信息的时间；还有执行计算所需的设置。

校准量子比特要做一系列环环相扣的测量，每一步的结果都会影响下一步。量子比特的特性偶尔会漂移，碰上意料之外的物理行为，结果也可能不稳定。有经验的研究人员能识别这些变化并随时做出调整。而这种「软件操控+重复测量+自适应决策」的组合，正好让量子比特校准成为 AI agent 的一块用武之地。

Yankelevich 拿一块还没校准的六量子比特芯片，来测 GPT‑5.6 Sol 跑测量的能力。这种芯片是 EQuS 用来基准测试自家制造工艺的标准款。她给 Codex 配了一组针对各种测量的专门技能（skill），每种实验该怎么跑、怎么评估都讲清楚。GPT‑5.6 Sol 就靠着这些技能和芯片的设计目标，自己挑参数、操作硬件、分析数据，完了要么细化这次的测量，要么把结果存下来供下一步用。

信号清楚的时候，Codex 几乎不用人插手就能跑完一整套标准测量。它会识别出量子比特的跃迁频率（transition frequency），校准用来控制和读出它的脉冲，再测出量子比特能保持量子信息多久。

EQuS 一次会造出不少这种标准芯片，每一块的特性表征都得花研究员好几天。现在组里已经把跑常规测量的活交给 agent 了，研究员能腾出手去做别的。

「我可以让 agent 整夜跑测量，或者我进洁净室（cleanroom）干活的时候让它自己跑上几个小时，」Yankelevich 说。「我用手机就能看它们的进展，需要修的地方、要换的方向，随时可以上手调整。」

与研究人员协同工作

最直接的好处是，Codex agent 能帮研究人员在没人盯着的情况下稳步推进实验分析和测量。有经验的研究员还是比当前的 AI 模型更快找到最佳校准设置。不过光是省下盯着每一步校准流程的时间，就够大家把精力放到别的事情上了。

常规芯片的特性表征走的是相对固定的流程。碰到新实验的时候，Yankelevich 会给 Codex agent 设定更窄的目标，但更倚重它们写、改、测试新代码的本事，控制代码、分析代码、仿真代码都能交给它们。把 agent 直接接到实验室，组里就能改代码、拿真实测量来验证，再让它们自主干上更长一段时间。

「我已经搭好了一套基础设施，能引导 agent 跑通我工作里的好几个环节，测量、理论、芯片设计都包括在内，」Yankelevich 说。「现在这套东西真的开始见效了。我可以同时让好几个 agent 处理不同的问题，自己大部分时间都花在高阶工作上，比如解读结果、设计实验、给 agent 规划下一步、读文献、写东西。」
