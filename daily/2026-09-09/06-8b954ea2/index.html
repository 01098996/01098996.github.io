GPT-6 Astra：新一代智能

GPT‑6 Astra 汇聚了多年来的研究成果以及在预训练（pre-training）、强化学习（reinforcement learning）和对齐（alignment）方面的重大投入。Astra 在计算机使用（computer use）、浏览、软件工程、网络安全（cybersecurity）、科学和专业工作等领域都达到了当前最优水平（state-of-the-art）。Astra 以 98% 的分数饱和了 FrontierMath Tier 4，并已帮助解决了一些长期悬而未决的开放性问题。Astra 还在 ARC-AGI-3 上以 99.9% 的分数、在 ExploitBench 上以 100% 的分数达到饱和。它还在计算机和浏览器使用方面树立了新的标杆，能以无与伦比的速度、准确度和判断力处理最严苛的专业工作。

GPT‑6 Astra 今日起开始向少数机构开放，未来几天内将面向所有 ChatGPT Plus、Pro、Business 和 Enterprise 用户开放，同时通过 OpenAI API、Microsoft Azure 和 AWS Bedrock 提供服务。

全球最强的计算机使用模型

GPT‑6 Astra 在计算机使用的速度、准确度和安全性方面树立了新的标杆。它可以处理繁琐的任务，比如填写在线表单、更新 CRM 中的客户记录以及整理日历。它可以进行在线研究，并在你的电子邮件或文档编辑器中起草摘要。它可以分析科学数据、生成图表、创建网站，并运行前端 QA 检查以确保该网站的所有功能正常运行。它可以帮助你自主安装和测试软件，并排查你在屏幕上看到的问题。这些改进也体现在我们当前最优水平的评估结果中。

这些改进也为实际知识工作任务带来了显著的效率提升。在 OSWorld 2.0 的延迟模拟中，Astra 在每个任务上比 GPT‑5.6 Sol 减少了约 47% 的时间，以约 40 分钟每个任务的时间取得了 72.6% 的成绩，而 GPT‑5.6 Sol 以约 75 分钟取得 65.7%。

专业工作的阶跃变化

GPT‑6 Astra 是我们迄今为止在遵循现有模板和制作排版精良、以结构化叙事简明传达关键要点的幻灯片方面表现最好的模型。它能创建清晰、结构良好的文档、演示文稿、电子表格和分析，遵循你的模板，并匹配你的写作和视觉风格。Astra 还经过专门训练，只在输出中纳入相关的上下文，而不是重复对当前工作不必要的信息。所有这些都意味着它能输出更即时可用的成果，匹配你的业务背景和标准。

GPT‑6 Astra 还为其所构建的网站、游戏、应用和渲染图带来了更强的视觉判断力。通过 ChatGPT 中的 Sites（在新窗口中打开），Astra 可以直接根据提示创建、托管和分享网站、Web 应用和游戏。

网络安全

正如我们在安全更新中讨论的，Astra 是网络能力的一次重大跃升，在我们的 Preparedness Framework 下达到了网络安全方面的 Critical 阈值。它识别和开发零日漏洞利用（zero-day exploits）的能力可以帮助防御者发现并修补弱点，但也带来了加强防护的必要性。为了理解这些能力的边界，我们在内部和第三方专家评估上运行了 Astra。

我们首先在未启用生产安全防护的情况下，在 ExploitBench 和 ExploitGym 上测试了模型，这两项基准评估模型能否将已知软件漏洞转化为可用的漏洞利用。在 ExploitBench 上，Astra 取得了 100% 的完美分数，而作为我们此前最强网络安全模型的 GPT‑5.6 Sol 为 78.5%。在 ExploitGym 上，Astra 达到了 42.4% 的成功率，而 GPT‑5.6 Sol 为 30.3%，同时输出 token 数量大幅减少。

考虑到接触历史软件漏洞可能影响基准结果的问题，我们还在两个新基准上评估了 Astra。其中之一，我们构建了一个内部"ExploitBench（2026 年 6 月–8 月）"评估，使用过去三个月的漏洞来测试漏洞利用开发。

Astra 在该数据集上以任意代码执行（arbitrary code execution）率显著高于 GPT‑5.6 Sol，同时输出 token 数量大幅减少。在评估过程中，Astra 甚至发现并利用了两个此前未知的零日漏洞。我们已向这两个漏洞的维护者披露了相关情况。

我们还在 SRE-Bench 上测试了 Astra，这是一项衡量模型能否在无源代码的情况下逆向工程软件二进制文件以理解其核心逻辑的基准。Astra 单次尝试即解决了 88.0% 的任务，四次尝试内解决了 99.2%，而 GPT‑5.6 Sol 的相应数据分别为 55.9% 和 68.7%。

在基准测试之外，专家主导的评估发现，Astra 在不启用生产安全防护的情况下，能够利用先前未知的漏洞在加固的浏览器中实现任意代码执行，并为加固的操作系统创建权限提升（privilege-escalation）漏洞利用。

正如我们在《The Defender's Window》中所讨论的，前沿的网络能力可以帮助防御者更快地发现弱点，但也使这些弱点更容易被利用，提高了防御者适应的紧迫性。通过今天推出的 Astra 版本，防御者可以用它来完成诸如安全代码审查和修补等任务。

然而，Astra 将拒绝执行更高级的网络安全任务，例如为漏洞创建概念验证（proof-of-concept）漏洞利用。通过 OpenAI Daybreak，我们计划在未来几周内扩大访问范围并推出限制更少的安全防护。这将支持更多防御性工作流，包括漏洞和概念验证验证、恶意软件分析和检测工程。

我们还加强了对潜在网络滥用的防护，这些防护建立在 GPT‑5.6 Sol 的安全防护堆栈之上。这些防护包括更强大的模型稳健性以更好地抵御潜在的越狱（jailbreak）以及为监控系统提供更多上下文。我们持续进行严格的内部和外部测试，包括使用内部红队测试（red-teaming）攻击者进行的自动化评估。关于我们的网络安全防护和测试的更多细节可在 Astra 安全概述和系统卡（在新窗口中打开）中查阅。

负责任地对齐和部署 GPT‑6 Astra

Astra 是我们迄今为止对齐程度最高的模型。Astra 在谨慎行事、尊重任务边界和透明沟通方面表现出色。这项工作是我们长期研究计划的最新成果，我们一直专注于训练从始至终都与人类意图保持对齐（aligned）的模型。

在敏感环境中，Astra 会以与其风险相称的谨慎行事。在一项针对恶意选择以诱发不良行为的计算机使用任务评估中，Astra 更成功地避免了意外后果。默认提供额外安全措施运行时，表现更强。

Astra 产生的不良对齐（misaligned）结果比任何其他测试过的前沿模型都少。为了公平比较，我们使用了一个通用的计算机使用代理（computer-using-agent）框架（基于 OpenAI Responses API（在新窗口中打开）和 Anthropic Messages API（在新窗口中打开）中均可用的原生计算机使用工具），且未启用通常部署给 Codex 和 ChatGPT Work 用户的额外防护（自动审查、确认策略）。

Astra 也更倾向于在用户设定的和由环境暗示的边界内运作。在一项内部评估中，Astra 从未试图规避 Codex Auto-Review 的拒绝。即使 Auto-Review 被故意配置为可规避，且任务在不规避的情况下不可能完成，这一结论仍然成立。这种对环境限制的尊重与我们在这篇文章开头分享的不可能网络安全任务评估的结果以及系统卡（在新窗口中打开）中记录的其他发现相一致。

Astra 还在透明的用户沟通方面创下新纪录。在一项评估中，Astra 对其能力和可执行操作做出不准确表述的可能性比 GPT‑5.6 Sol 低三倍。

在我们的能力幻觉（capability-hallucination）评估中，Astra 较 GPT‑5.6 Sol 有了实质性的改进，对其能力做出误导性主张的情况更少。

我们的评估发现，与 GPT‑5.6 Sol 相比，Astra 的书面推理更难监控，评估基于明确要求其规避监控的测试。我们将此归因于 Astra 在更简单任务上对书面推理的更强控制力以及用更少的书面步骤解决问题的能力。Astra 仍然似乎在隐藏解决复杂任务所需的推理方面存在困难，但我们严肃对待这种下降。提升可监控性（monitorability）仍是研究重点，配套的系统卡（在新窗口中打开）详细记录了我们的发现和正在进行的工作。

对齐训练是我们部署方法的核心。作为额外的防御层，我们还构建了系统防护，例如 Codex Auto-review（在新窗口中打开）以及监控代理的推理和行动，以帮助检测和遏制不安全行为。正如我们在安全更新中所描述的，我们还在生产中为 Astra 级模型部署不良对齐监控，以便掌握不良对齐的情况并帮助遏制最严重的实例。这些防护措施与我们对内部部署的监控类似，涉及一套分类器系统，用于检查模型的推理和行动是否存在未授权行为，并自动停止潜在未授权的活动。

鉴于 Astra 网络安全能力的显著提升，我们对此次部署的安全性和保密性格外谨慎。额外的安全检查有时会减慢、暂停或停止合法工作，包括防御性网络安全。如果一项任务在 ChatGPT 或 Codex 中被暂停，你可能会被要求在继续之前审查该操作。在 API 中，任务将停止。这些检查有时会打断合法工作，我们正在持续迭代该系统以减少不必要的打断。不良对齐监控不能取代对齐：我们的目标是构建能够可靠地保持在授权范围内的模型，从而使这些防护无需介入。

可用性

GPT‑6 Astra 今日起开始向少数机构开放，未来几天内将面向所有 ChatGPT Plus、Pro、Business 和 Enterprise 用户开放，同时通过 OpenAI API、Microsoft Azure 和 AWS Bedrock 提供服务。Astra 的使用包含在现有的订阅额度内，用户和企业也可以购买额外用量的积分。Pro、Business 和 Enterprise 计划的用户还将获得 GPT‑6 Astra Pro 的访问权限。企业管理员可以为其工作区启用 Astra；发布时该访问权限默认为关闭。

Astra 支持符合资格的 API 客户的 Zero Data Retention，而且正如我们上个月所分享的，我们正在测试 Private Safety Processing，以在保护客户隐私的同时加强安全监控。

对于开发者，GPT‑6 Astra 将以 gpt-6-astra 的形式在 OpenAI API 中提供，并通过 Microsoft Azure 和 Amazon Bedrock 提供。

OpenAI API 标准定价为每百万输入 token 10 美元、每百万输出 token 50 美元。缓存读写另计费率。GPT‑6 Astra 在 API 中提供 Fast 模式，速度可达标准处理的两倍，定价为标准模式的两倍。
