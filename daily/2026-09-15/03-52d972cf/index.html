agentverse-os/AgentVerse-OS

AgentVerse OS 是一个面向开发者及其 AI 智能体（agent）的个人云操作系统：在一台服务器上运行你自己的云，通过浏览器在任何设备上使用。它以跨平台 vibe coding（凭直觉编码）流程的方式构建：同一套桌面、工作区（workspace）和智能体在笔记本电脑、平板或手机上打开，工作区及其智能体始终驻留在服务器上，工作可以从你离开的地方继续。

一条命令即可在干净的 Ubuntu 上完成安装；之后所有操作都在浏览器中进行：一个窗口化的桌面、带有 VS Code 和智能体（Claude Code、Codex）的隔离工作区、一个包含 944 个自托管应用的商店（Store）、备份和更新。所有内容都不暴露在公网上：访问通过 Tailscale 进行，使用真实证书，无需在设备上安装根 CA。

该项目处于 alpha 阶段，运行在一台测试机上。它作为单人使用的个人服务器工作；目前还没有用户账号或权限。请参阅 Status（状态）部分了解已完成和未完成的内容。

它长什么样

桌面在电脑上：Store（应用商店）目录、项目卡片（包含工作区和能力）、小部件（widget）。Monolith 主题，玻璃质感表面。

浅色主题：项目和外观设置。七种预设，包括 OLED 和高对比度。

平板：相同的窗口和小部件，竖屏壁纸。

手机：替代桌面的主屏幕、全屏窗口、PWA（渐进式 Web 应用）。同一个桌面会自动适配设备。

它能做什么

项目和工作区

每个项目拥有自己的网络、自己的网关（gate）以及一个内含 Docker 的隔离 Incus 容器。

内部包括：浏览器中的 VS Code、终端以及智能体；Claude Code 和 Codex 用你自己的订阅登录。停止/启动操作保留实例，资源可通过项目卡片修改。

944 个应用的 Store

将 Runtipi、Coolify 和 Umbrel 三个目录合并为一个，并带有来源徽标。引导式安装、凭据直接显示在卡片上、日志、数据目录权限的自动修复、应用之间的链接（例如 n8n → LiteLLM）、按应用的快照（snapshot）和回滚（rollback）。

用能力（capability）代替地址

项目请求 storage.s3、llm 或 notify；核心（core）将项目的网关连接到提供者的网络，并向工作区注入环境变量。将 Garage 替换为另一个 S3 不会影响项目本身。

仅浏览器使用

首次运行向导通过链接或二维码加入 Tailscale，检查 DNS 和证书，并创建第一个项目。

系统和应用更新通过 Updates 窗口获取：更新以包的形式发布，如果新版本无法启动则自动回滚。

备份

定时 ZFS 快照以及对快照进行备份的 restic 仓库；两次点击即可回滚单个应用。默认关闭。

像桌面操作系统一样的桌面

窗口、任务栏、开始菜单、小部件（显示器、时钟、新闻、天气、项目）、基于应用数据和 workspace 主目录的 Files（文件）、Passwords & Access（密码与访问）、主题和壁纸、启动画面、离线提示层、屏幕保护程序。界面支持英语、俄语、乌克兰语和西班牙语；语言跟随浏览器或在所有设备上统一设定一次。

目录中已有两个助手

Hermes Agent，带有 Web 面板；以及 Pipecat Voice，一个浏览器内的语音助手，支持本地语音识别与合成。系统本身的语音控制已在路线图上。

核心很小：七个实体（project、workspace、gate、app、capability、grant、route）和四份契约（contract）。其余全部是经过验证的第三方软件：Coder 运行工作区，Incus 隔离工作区，Komodo 部署 compose 栈，Caddy 持有入口点，Tailscale 提供网络和证书。

快速开始

你需要一个干净的 Ubuntu 22.04+（已在 26.04 上测试），8 GB 及以上内存，最好有一块独立磁盘用于 ZFS，以及一个 Tailscale 账号。

从发布包安装，无需构建：

curl -LO https://github.com/agentverse-os/AgentVerse-OS/releases/download/v0.2.0/agentverse-os-0.2.0-x86_64.tar.gz
mkdir agentverse-os&&tar xzf agentverse-os-0.2.0-x86_64.tar.gz -C agentverse-os&&cd agentverse-os
sudo DISKS="/dev/disk/by-id/<disk for ZFS>" bootstrap/install.sh

或从源码构建：

git clone https://github.com/<owner>/agentverse-os&&cd agentverse-os
cd desktop&&npm install&&npm run build&&cd..

#Desktop → cloudd/static
cd cloudd&&cargo build --release&&cd..

#core with the Desktop embedded
sudo DISKS="/dev/disk/by-id/<disk for ZFS>" bootstrap/install.sh

安装程序按步骤执行：主机检查 → ZFS → Docker 与 Incus → Tailscale（用于授权节点的链接和二维码，等待你的确认，检查 MagicDNS 和 HTTPS 证书） → Coder → Komodo → edge（边缘层） → core（核心） → catalog（目录） → template（模板） → 包含地址的摘要。检出（checkout）也可以从包而不是本地构建的二进制文件进行安装：PACKAGE=agentverse-os-<version>-<arch>.tar.gz（可以是本地文件或 https URL）；包由 scripts/release.sh 构建。

完成后，打开 https://<node>.<tailnet>.ts.net/，首次运行向导将在浏览器中完成设置。更新通过 Updates 窗口或 sudo agentverse-update 获取；更新通道是最新发布的 stable.json，例如：

https://github.com/agentverse-os/AgentVerse-OS/releases/download/v0.2.0/stable.json。

仓库目录内容

cloudd/：用 Rust 编写的核心（axum、rusqlite、bollard）：/api/* API（共 60 条路由，OpenAPI 位于 /api/openapi.json）、CLI、嵌入式 Desktop；Incus、Docker、Coder、Komodo、Caddy 的适配器；备份、更新、首次运行向导。

desktop/：使用 Svelte 5 和 Vite 编写的 Desktop，PWA：窗口、小部件、Store、Files、Passwords、Settings；四种语言的字典位于 src/lib/i18n/；npm run build 输出到 cloudd/static。

store/app 清单：manifest.yaml compose.yaml；938 个从 Runtipi、Coolify 和 Umbrel 导入，6 个手写；recommended.yaml。

bootstrap/：install.sh、update.sh（安装后命名为 agentverse-update），edge / Coder / Komodo / docker-proxy 的 compose 文件，主机脚本，systemd 单元。

templates/incus/：Coder → Incus 工作区模板。

assets/：Monolith 标识、组合标志、PWA 图标、壁纸、字体、截图；build.py 将所有内容组装到 desktop/public。

scripts/release.sh：构建更新包和通道清单；demo/ 包含本文 README 的演示数据和截图流水线。

tests/：在真实测试机上的端到端测试，安装程序的 shell 测试；使用 Playwright 的 Desktop e2e 测试位于 desktop/e2e/。
