Turkish Native 是一个用于撰写和编辑自然土耳其语的开源 agent（智能体）技能。它针对的是 AI 生成和本地化文案中的一种特定失效模式。语法上能读懂，但仍然带着外语句法结构、不自然的搭配、对 SaaS（软件即服务）或销售用语的生硬仿译（calque）、内部产品术语，或模型生成的营销套话。

一个句子语法上正确，听起来仍然像是翻译过来的。

为什么存在

拼写检查器和语法工具能抓到机械层面的错误。Turkish Native 比它们再往上一层，处理的是母语级句式构造。它让 agent 从语义出发把句子重建，而不是保留源语言的骨架。

具体来说，先查句法再查词汇。从句、名词化（nominalization）、语序、格后缀、所有格、动名搭配、产品用语、语域（register）、事实准确度，再到页面级的领域一致性。

适用场景

把 Turkish Native 用在营销、产品 / UI 文案、SaaS、本地化、文档、客服支持、法律 / 隐私 / 安全类文本、机构沟通、自动生成的商务页面，以及对 AI 写出来的土耳其语做审校。

它不是拼写检查器，也不是 AI 检测器或外来词黑名单，更不能替代专业法律审查。它也没说土耳其语只有一种正确的表达方式。

用法

- 用 $turkish-native 审阅这段土耳其语文案。
- 标出翻译腔（translationese）和不自然的搭配，改写成自然表达。
- 用 $turkish-native 把这段文字翻成自然的土耳其语。
- 保留事实和产品术语，但不要保留英语句式结构。
- 用 $turkish-native 改写 src/content/tr/home.ts 里的正文。
- 键名、变量、URL、代码、路由名称保持不变。
