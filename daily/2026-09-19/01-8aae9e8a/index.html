Claude Code 2.1.277 更新：自动模式服务端分类器与 AGENTS.md 支持

Claude Code now reads AGENTS.md if there is no Claude.md

Claude Code 现在在没有 Claude.md 时会读取 AGENTS.md

为 Claude API（应用程序编程接口）和 Enterprise 用户，以及在 Bedrock、Vertex、Foundry 和各网关（gateway）上，把自动模式（auto mode）的默认值改为使用服务端分类器（classifier），不再为分类器开销计费（在 Bedrock、Vertex、Foundry 和各网关上可通过设置 CLAUDE_CODE_AUTO_MODE_SERVER=0 选择退出）；对会计费的回退路径发出警告。参见官方自动模式分类器计费说明文档。在 /status 中新增了一行 Auto mode server（自动模式服务端），用于显示当前会话的自动模式分类器是否运行在服务端。

2.1.277 September 18, 2026

新增 AGENTS.md 支持：在没有 CLAUDE.md 的项目中，Claude Code 会改为读取 AGENTS.md；可在 /config 的 "Project instructions"（项目指令）下更改此设置（在 Bedrock、Vertex 和 Foundry 上暂不支持）。

为 Claude 应用网关新增 CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1：当网关唯一的出站（egress）流量都经过一个转发代理（forward proxy）时，每个出站请求都会把主机名直接交给代理，而不是在本地解析。

为 Claude 应用网关的上游（upstream）新增可选的 headers: 映射（map），用于向你运行在某个提供商前面的代理发送静态请求头。

在某个后台任务结束时，如果 /tasks 这类面板处于打开状态，会新增一行提示，告知有一条该任务的更新正在等待查看。

修复了 claude -p 和 Agent SDK（软件开发工具包）会话在发生内部错误后可能挂起且无任何返回结果的问题；现在它们会上报错误并以退出码 1 退出。

修复了在先前的某条助手回合中保存了一个空的文本块（text block）与其他内容并存时（包括在 --resume 之后），每次请求都会失败并提示 "text content blocks must be non-empty" 的问题。

修复了在同一台机器上同时运行旧版 Claude Code（例如某个 IDE 集成开发环境扩展内置的 CLI（命令行工具））和当前版本时，会被意外登出的问题。
