FAQ

Pirate Face 是什么？一个面向主权 AI（sovereign AI）的去中心化、点对点（peer-to-peer）层。Hugging Face 上的开源模型会变成经过校验和验证的 torrent，由全球分布式节点网络持有，从而扛得住任何单一主机的下架。目标就是让开源 AI 持久存在。

我需要账号才能使用 Pirate Face 吗？不需要。你可以无需账号浏览、下载和做种。Claim 主页是可选的。

公开 claim 会为你预留 Pirate Face 主页，并帮助网络扩散。只有你的首个符合条件的主页可获得欢迎积分。

Hugging Face 创作者的 claim 需要验证。要获得当前 Hugging Face 用户名或组织的 Verified creator 徽章，你必须验证对应的 Hugging Face 账号。在此之前，主页只是处于预留状态，并不能证明身份。

正在规划直接发布。账号最终将支持在 Pirate Face 上直接发布和管理模型，而无需先上传到 Hugging Face。该功能尚未上线。

目前，提交一个模型需要 Hugging Face 账号，并且该模型必须已经在 Hugging Face 上。

账号还将支持未来的社区福利，详见账号福利。

为什么要创建 Pirate Face 账号？账号为你提供管理已预留主页与追踪贡献记录的地方。Claim 主页会为你预留一个公开主页；验证匹配的 Hugging Face 身份可获得 Verified creator 徽章，并防止冒充。

Pirate Face 正在为账号持有者准备社区福利，包括免费算力积分和独家模型发布。

你无需账号即可浏览、下载和做种。

既然目标是摆脱中心化托管，为什么还要使用 Hugging Face 验证？Hugging Face 验证是为了确认某个声称为创作者的人确实控制着对应的 HF 账号或组织。它有助于防止冒充，并在模型扩散到原始主机之外时保留署名归属。

你无需验证，也无需账号，即可浏览、下载或做种。

Pirate Face 的近期目标是让模型的可用性超越任何单一托管平台。目前，Pirate Face 的部分功能依赖 Hugging Face 及其社区。Pirate Face 正致力于尽快允许直接发布模型，而无需先上传到 HF。

我的 Pirate Face 主页必须与我的 Hugging Face 用户名一致吗？不必。你可以预留一个可用的名字，但 Verified creator 徽章要求有匹配的 Hugging Face 身份。

例如，一个名为 john123 的 Hugging Face 账号可以验证 john123，但不能验证 john。你仍然可以预留 john，但它会保持未验证状态。匹配的 Hugging Face 所有者可以收回该主页，而无需删除你的 Pirate Face 账号。

在 Account 中管理你关联的账号与已预留主页。

有人能在这里冒充创作者吗？两者均受保护：

- 权重无法伪造，每个文件都根据 Hugging Face 的官方 SHA-256 进行校验和验证。
- 主页可被收回，任何人都可以预留一个名字（页面会显示已预留，没有 Verified creator 徽章），但只有证明匹配的 Hugging Face 身份才能获得 Verified creator 徽章。占用者无法将你拒之门外：真正的所有者可以通过验证来收回已预留的名字。

"校验和已验证"是什么意思？每个权重文件都携带其官方的 Hugging Face SHA-256，一组能唯一标识确切字节的指纹。无论从哪里下载，哈希都必须匹配，这样你就始终能确认拿到的是真正的权重，而不是被篡改的副本。这是镜像模型的头号担忧，所以在这里它是一项核心功能。

下载是如何进行的？如果 Hugging Face 删除了一个模型会怎样？每个模型都是一条磁力链接（magnet link，即 torrent），里面内置了 Hugging Face 的网络种子（web-seed），因此即使没有任何对等节点也能工作。

模型仍在 Hugging Face 上：你直接从 HF 拉取字节，同样的权重，经过校验和验证，同样的速度。

HF 删掉它的那一天：web-seed 失效，下载回退到点对点分布式网络。我们将其标记为 Rescued（已拯救），仍可访问，由所有正在做种的人维持。

这种回退正是核心所在：字节与直接从 Hugging Face 下载完全一致，但没有单点故障（并且分布式网络可以比远离 HF 的地区服务得更快）。

我可以添加自己的模型吗？可以，只要你有一份还存活的副本，就可以提交一条带有来源证据的磁力链接。打开模型页面时，如果存在 Hugging Face 校验和，就会被自动记录。仅仅上架并不等同于下载，上架也不会开始做种。

匹配固定版本（pinned revision）的 Hugging Face LFS 哈希时，模型会立即被列出。不匹配或来源已消失的会留在审核队列中。

Pirate Face 从 Hugging Face 进行镜像，所以模型必须先存在于 Hugging Face。如果你的模型还没在 HF 上，去那里上传（免费），然后再在这里提交。

什么是 "web-seed"？唯一值得了解的一个术语。web-seed（BitTorrent 规范 BEP-19）是一条普通的 HTTPS 链接，被嵌入到 torrent 里，这里指的是模型在 Hugging Face 上的文件。它说到底就是下载链接，作为保证来源被内置在 torrent 中，这正是模型即使在零对等节点时也能下载的原因，也解释了为什么那个链接一失效，分布式网络立刻就会接管。

什么是 drop-in API？设置 HF_ENDPOINT=https://pirateface.co，你现有的 pipeline 就会通过我们来解析模型，Hugging Face 还在时走 Hugging Face，一旦不在则立刻走分布式网络。同样的路径，同样的 API，零代码改动。

什么是积分（points）？积分用于在排行榜上表彰参与。它们既不是货币，也不是算力积分余额。

- 欢迎积分：每个账号仅一个符合条件的主页。额外的预留和关联 HF 不会再获得奖励。将你的 claim 关联到账号即可符合条件。
- 推荐：新账号的首个主页为你带来 50 积分，推荐人账号至多可计入 10 个被推荐人。自我推荐和额外主页不予计入。
- 已拯救的模型：每个不同的已拯救模型 25 积分，计入其首个已验证主页。
- 做种奖励：已在规划中，尚未启用。我们需要可归因的做种证据才能发放奖励。

Pirate Face 正在构建一个贡献者生态，正在规划的社区福利包括免费算力积分和独家模型发布。资格、限额与上线日期将在福利正式可用前公布。积分不会自动转化为额度，预留更多主页也不会提升你的福利。
