快速上手

需要 Python ≥ 3.11、FreeCAD 与一个在 FreeCAD 内运行的兼容桥接器。请单独安装并启动 Robust MCP Bridge 工作台，使用 socket 端口。FreeCAD 与桥接器工作台需分别安装。

在项目目录下安装并检查连接：

python3 -m pip install
freecad-nexus --mode socket --host 127.0.0.1 --port 9876 --check

将此配置添加到你的 MCP 客户端。如果客户端找不到可执行文件，请使用其绝对路径作为 command：

{"mcpServers": {"freecad-nexus": {"command": "freecad-nexus", "args": ["--mode", "socket", "--host", "127.0.0.1", "--port", "9876"]}}}

对于 XML-RPC，使用 --mode xmlrpc --port 9875。现有的 FREECAD_* 环境变量仍然受支持；运行 freecad-nexus --help 查看可用选项。桥接器可以执行 Python，因此请将其连接到受信的本地 FreeCAD 会话。
